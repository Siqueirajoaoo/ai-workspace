Politique de confidentialité

Ce texte est un brouillon de structure, pas une version juridique définitive. Il sera revu avant tout lancement commercial.

1.Où se trouvent les données

Dans cette version, tout ce que vous créez est stocké uniquement dans votre navigateur, sur votre propre appareil. Aucun serveur ne reçoit vos données.

2.Quelles données existent

Le nom et l’e-mail saisis dans le compte local, les préférences d’apparence et de langue, et le contenu que vous créez dans les modules.

3.Partage

Nous ne partageons aucune donnée avec des tiers. Aucun service externe d’analyse, de publicité ou de suivi n’est utilisé.

4.Vos contrôles

Vous pouvez supprimer le compte local et toutes les données à tout moment dans les Paramètres. Effacer les données du navigateur supprime aussi tout.

5.Évolutions futures

Quand il y aura des comptes dans le cloud, cette politique sera réécrite pour expliquer le stockage sur serveur, la conservation et vos droits.
